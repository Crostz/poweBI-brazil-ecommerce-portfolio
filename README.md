# ¿Dónde está el riesgo detrás del crecimiento? Análisis Olist Brazil 2016-2018

Fuente de datos: Brazilian E-Commerce Public Dataset by Olist en Kaggle

Preguntas de negocio que responde el dashboard:
1. ¿Cómo evoluciona el ingreso mensual y qué método de pago se usa con más frecuencia?
2. ¿Qué categorías de producto generan más ingresos por venta de productos pero tienen mayor tiempo promedio de entrega?
3. ¿Qué estados concentran más ingresos por ventas y cuáles tienen peor promedio simple de review_score? 
5. ¿Qué vendedores tienen mayor cantidad de artículos vendidos pero peor promedio de review_score?
